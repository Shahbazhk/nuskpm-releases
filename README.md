# nuskPM Downloads

Ready-to-run installers for nuskPM — a project management app covering
predictive, agile, and hybrid delivery.

No prerequisites needed (no Python, Docker, or Node) — just download and run.

Grab the latest release for your OS from the
[Releases page](https://github.com/Shahbazhk/nuskpm-releases/releases/latest):

- **Windows** — `nuskPM-Setup.exe`
- **Linux** — `nuskpm_<version>_amd64.deb`
- **macOS** — `nuskPM-<version>.dmg`

After installing, launch nuskPM from your Start Menu / Applications folder —
it opens in your browser automatically.
